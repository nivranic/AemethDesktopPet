# Aemeath Mini Pixel Pet

独立 Windows 像素桌宠，可通过 ZCode hooks/MCP 显示任务动画。当前版本 **0.3.6**。本项目不是 ZCode、Codex 或角色权利方的官方产品。

## 启动与控制

Windows 10/11，使用系统 .NET Framework 4.x；ZCode 集成另需 Node.js 18 或以上。

1. 将完整文件夹解压到固定位置，双击 `bin/ZCodePet.exe`。不要只复制 EXE，图集位于 `assets/aemeath-mini`。
2. 重复双击会显示已有桌宠，不会重复创建常驻实例。
3. 右键桌宠或托盘图标可设置速度、大小、鼠标观察和减少动态效果；双击托盘图标切换显示。菜单为现代扁平样式（浅色背景、圆角悬停高亮、Win11 圆角），并在宠物旁边弹出以避开置顶宠物的遮挡；打开后按 Esc 或点击菜单外任意位置即可关闭。
4. “隐藏”保留托盘并停止动画计时器；“退出桌宠”结束进程，任务事件不会把它重新拉起。
5. “随 Windows 登录启动”可随时开启/关闭，只影响当前用户。新安装默认不创建登录项；升级保留已有选择。关闭程序与关闭登录自启是两个独立操作。
6. “重启资源管理器”与全局热键 **Ctrl+Alt+R** 用于任务栏/资源管理器假死时的自救，见下节。

登录启动使用 `--wait-host`：ZCode 出现时显示，退出后隐藏，进程继续驻留托盘。手动双击则立即显示。程序不要求管理员权限。

鼠标悬浮时播放跳跃；每次移开后播放三轮墨镜互动动画（1×速度约 2.46 秒），待机时也会播放。移回会切换到悬浮动画，下次移开重新播放。该效果不改变任务状态，结束后恢复实际状态；启用“减少动态效果”时只显示静态墨镜帧。

## 重启资源管理器（任务栏假死自救）

系统在重负载下出现“任务栏假活/资源管理器卡死”（点击任务栏无响应、无法打开新窗口、任务管理器呼不出）时，右键桌宠或托盘图标选择“重启资源管理器”，或随时按 Ctrl+Alt+R。执行顺序按极端场景设计：

1. 先拉起一个一次性看护进程（普通子进程，桌宠自身意外死亡也会独立完成收尾，最长存活约 90 秒）；
2. 用 TerminateProcess 强制结束当前会话所有 explorer.exe（不依赖其消息循环，挂死也能杀）；
3. 800 毫秒后直接 CreateProcess 拉回 explorer.exe，失败则每 1.5 秒重试至多 4 次；
4. 看护进程持续确认 shell 存在，缺失时以直启、系统 WMI 两条路径拉回。

以当前用户权限即可重启本会话的资源管理器，无需管理员。重启会关闭已打开的文件夹窗口；15 秒内重复触发会被防抖忽略。全部触发与结果记录在 `lifecycle.log`（`explorer-restart` / `explorer-watch` 前缀）。若整机输入完全冻结（鼠标能动但点击键盘全无响应），用户态程序无能为力，需按电源键长按强制重启并排查系统层原因。

## ZCode 集成

发布包可作为本地插件目录，或通过配套 marketplace 安装。请使用 ZCode 支持的插件注册方式，避免同时加载源目录和市场副本。更新后重新加载插件，以刷新可能缓存旧代码的 MCP 服务。

| 工具 | 行为 |
|---|---|
| `pet_show` | 用户明确要求时直接启动/显示桌宠，允许任务事件显示已有窗口 |
| `pet_hide` | 隐藏并禁止任务事件再次显示，托盘仍在 |
| `pet_quit` | 退出并保存用户选择 |
| `pet_status` | 只读取状态，不启动程序 |
| `pet_set_state` | 临时演示动画，不能当作真实任务结果 |
| `pet_configure` | 配置速度、大小、鼠标观察和减少动态效果 |

任务 hooks 只连接已运行的桌宠，不创建进程。明确的显示/演示/配置命令可以直接启动 EXE；需要独立于宿主生命周期时，请通过桌面或登录启动。桌宠自身生命周期不含 WMI 启动、隐藏 PowerShell、定时复活或守护服务；唯一例外是用户主动触发的“重启资源管理器”，它会临时拉起一个最长约 90 秒的一次性看护子进程，并可能经系统 WMI 服务拉回 explorer.exe，全程记录于 lifecycle.log。

权限等待映射 waiting、工作映射 running、工具失败映射 failed、正常 Stop 映射 review。宿主缺少的网络错误、手动取消、已读等事件无法完整覆盖。失败与审查动画也可在空闲时轮换，因此动画不能替代真实任务结果。

## 数据、权限与许可

- 默认离线，无遥测、自动更新、广告或下载执行。
- 只接收任务状态与摘要会话标识，不接收聊天正文、工具参数或输出。
- 鼠标观察默认关闭；不读取键盘、不截屏。
- 设置和限量日志保存在 `%LOCALAPPDATA%\ZCodePixelPet`。
- IPC 限当前 Windows 用户，显式拒绝网络登录，限制消息大小及命令集合。

## 排错与移除

启动失败时检查用户目录的 `startup-error.json` 和系统提示。管道被占用会明确启动失败，不在后台无限重试。某安全产品的名称标注不能单独说明检测规则；本项目不修改安全软件设置。

移除时先退出桌宠，关闭“随 Windows 登录启动”，再从 ZCode 移除插件注册，最后删除解压目录。个人设置默认保留；需重置时可在退出后自行删除上述数据目录。旧版本的保活任务可用源码维护工具检查、备份并移除。
