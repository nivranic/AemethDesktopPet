# 360 标注问题的本地整改（0.3.2）

用户确认 360 加速球将本程序标为“病毒木马程序”，并授权处理。该显示不能独立证明恶意代码，也不能确定检测规则。本次不修改安全软件配置，不声称整改可直接清除标签。

## 方案与边界

采用普通托盘程序：用户双击或既有 HKCU Run 登录启动项直接启动 EXE；插件 hooks 仅连接已运行的程序，明确的 pet_show 可以直接启动。取消 WMI、隐藏 PowerShell 启动链和定时复活。保留本地命名管道、托盘菜单、显示/隐藏选择和任务动画。

仅补充文件信息无法解决启动设计问题；增加服务或另一层守护进程没有必要。暂不具备可信代码签名证书，保持签名状态如实记录。

## 实施顺序

1. 备份源码、二进制及旧任务、登录项状态。
2. EXE 支持无参数启动、重复启动唤出已有窗口；错误记录到用户目录并给手动启动提供可见提示。
3. 移除脚本式启动和自动重生，显式启动保留错误传播。
4. 补齐程序集产品信息、版本、图标及 asInvoker 清单。
5. 停用已核对动作路径的旧保活任务，简化既有登录项为直接启动 EXE；不新建自启。
6. 运行 Node 回归、原生绘制/管道自测和真实桌面启动、重复启动、退出后 hooks 不重生的检查。
7. 更新发布副本、哈希和证据，准备只含必要文件的误报复核材料。

## 验收与回滚

功能验收与 360 判定分开记录。只有在 360 中实际复查后才能报告标签是否消失；提交样本不代表厂商已受理或已解除。

回滚时先退出新程序，再从本次备份恢复插件目录。旧任务 XML 和登录项值保留用于追溯；不建议恢复定时复活机制。整个工作区不是 Git 仓库，本次以文件备份与哈希核验交付，不创建提交。
